App guide

🎬 Promptus Media Lab

React editing-cue workspace that uses Gemini to draft dialogue, audio, visual and effect markers for a timeline.

Explore the source →

What it does

The public repository named 42 contains this Media Lab application. It is separate from the 42.uk website catalog and from 42 MOMM Diffusion.

The app uses React, TypeScript and Vite, with Gemini for structured editing cues and ffmpeg.wasm for browser media handling. This is an editing-cue workspace, not a claim of automatic finished-video generation.

What you need

Node.js for local development and your own configured Gemini access for AI cue generation. Provider use may incur charges.

Run locally

git clone https://github.com/marroccofella/42
cd 42
npm install
npm run dev

See the repository README for provider configuration. This GitHub Page documents the app; it does not run the editing workspace or make generation requests.
